# Systems in Depth

백엔드·풀스택 엔지니어 3D 포트폴리오 · https://sungbae-dev.github.io

청사진 도면 콘셉트의 단일 페이지 사이트입니다. 빌드 단계 없이 `index.html` 하나로 동작합니다.

## 구성

| 시트 | 3D 연출 |
| --- | --- |
| 01 개요 | 커서를 피하는 파티클 코어, 글자 단위 3D 히어로, 스크롤 시 깊이 방향 후퇴 |
| 02 작업 | 스크롤 Z-터널: 프로젝트 카드 6장 사이를 카메라가 통과, 클릭하면 카드 뒤집기 |
| 03 스택 | 5층 분해도, 드래그 관성 태그 구체 |
| 04 연락 | 14겹 압출 헤드라인, 커서로 끌려오는 파티클 포털 |

- 페이지 전환: 시트가 큐브 면처럼 회전하고, 파티클이 다음 형태로 모핑되며 후처리 셰이더가 왜곡·글리치를 겁니다.
- 커서: 레이 기반 파티클 반발, 클릭 충격파, 속도 연동 색수차, 제도용 십자선 커서.
- `#work`, `#stack`, `#contact` 해시로 시트를 바로 엽니다. 숫자키 1–4로도 이동합니다.
- 다크/라이트 테마, 모바일, `prefers-reduced-motion`, WebGL 미지원 환경을 처리합니다.

## 기술

Three.js r128 (커스텀 GLSL 포인트 셰이더 + 렌더 타깃 후처리), CSS 3D Transforms, Web Animations API. 프레임워크와 번들러는 쓰지 않았습니다.

## 로컬 실행

python3 -m http.server 8000
