# Systems in Depth

Forward Deployed Engineer · SI · DevOps 포트폴리오 · https://sungbae-dev.github.io

고객 현장에 들어가 시스템을 설치하고, 기존 시스템과 연동하고, 운영까지 책임지는 백엔드·풀스택 엔지니어의 3D 포트폴리오입니다. 청사진 도면 콘셉트의 단일 페이지이고, 빌드 단계 없이 `index.html` 하나로 동작합니다.

## 구성

| 시트 | 내용 | 3D 연출 |
| --- | --- | --- |
| 01 개요 | 역할, 배포 현장, 담당 범위, 작업 원칙 | 커서를 피하는 파티클 코어, 글자 단위 3D 히어로, 스크롤 시 깊이 방향 후퇴 |
| 02 작업 | 전자정부 · 의료 SI · 서버 운영 · 레거시 이전 · 블록체인 | 스크롤 Z-터널, 파티클 서버 랙 사이를 카메라가 통과, 클릭하면 카드 뒤집기 |
| 03 스택 | 인프라 → 데이터 → 애플리케이션 → 프론트엔드 → 현장 | 5층 분해도, 드래그 관성 태그 구체 |
| 04 연락 | 포지션 제안과 의뢰 | 14겹 압출 헤드라인, 커서로 끌려오는 파티클 포털 |

- 페이지 전환: 시트가 큐브 면처럼 회전하고, 파티클이 다음 형태로 모핑되며, 후처리 셰이더가 왜곡과 글리치를 줍니다.
- 커서: 레이 기반 파티클 반발, 클릭 충격파, 속도 연동 색수차, 제도용 십자선 커서.
- `#work`, `#stack`, `#contact` 해시로 시트를 바로 엽니다. 숫자키 1–4로도 이동합니다.
- 좌하단 팔레트 버튼으로 모드(다크·라이트·시스템), 프리셋 5종(청사진·흑연·산화 구리·자정·신호), 포인트·선 색을 직접 바꿀 수 있습니다. 파티클과 그리드 셰이더도 같이 바뀌고, 선택은 브라우저에 저장되어 첫 화면부터 적용됩니다.
- 모바일, `prefers-reduced-motion`, WebGL 미지원 환경을 처리합니다.
- 렌더 루프는 `requestAnimationFrame` 기반이고 모든 움직임이 프레임 시간(dt)으로 계산됩니다. 144Hz 같은 고주사율 화면에서는 그 주사율 그대로 돌아갑니다.

## 기술

Three.js r128(커스텀 GLSL 포인트 셰이더, 렌더 타깃 후처리), CSS 3D Transforms, Web Animations API를 썼습니다. 프레임워크와 번들러는 쓰지 않았습니다.
